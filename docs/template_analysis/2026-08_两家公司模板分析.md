选择原则：保留重复出现的标准业务，以及每月通常只做一笔的工资、社保、公积金、折旧、税金计提；不按交易对手逐个创建模板。一次性调整、资产处置、混合报销、内部划转和本期损益结转不纳入。覆盖率按完整凭证计算，仅表示历史分录结构可复现，不表示后续单据均可自动分类。
